# NWC 악보 (웹 앱)

NoteWorthy Composer 악보 파일(`.nwc`, `.nwctxt`)을 아이패드·아이폰·안드로이드·PC 브라우저에서 보고 재생하는 웹 앱입니다.
한 번 열어 두면 인터넷 없이도 동작합니다(오프라인 캐시). 악보 파일은 서버로 올라가지 않고 각 기기 안에만 저장됩니다.

## 아이패드에서 설치

1. Safari로 앱 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**.
3. 이후에는 홈 화면 아이콘으로 실행합니다(인터넷 없이도 열림).
4. 카카오톡 등에서 받은 .nwc 파일은 먼저 **파일 앱에 저장**한 뒤, 앱의 "악보 파일 열기"로 불러옵니다.

## 기능

- 악보 표시(음표·쉼표·화음, 셋잇단, 붙임줄·이음줄, 셈여림, 도돌이표, 1·2번 괄호, D.S./Coda, 여러 절 가사)
- 재생: 반복·괄호·D.S./D.C./To Coda/Fine 순서, 파트별 소리·볼륨(재생 중 바로 반영), "내 파트" 강조
- 빠르기 50~150%, 마디를 눌러 그 위치부터 재생, 재생 위치 자동 따라가기, 확대/축소

## 구성

- `js/nwc.js` 파일 해석, `js/perform.js` 연주 순서, `js/layout.js`·`js/render.js` 악보 그리기, `js/audio.js` 내장 신시사이저
- `sw.js` 오프라인 캐시 — 파일을 고치면 `VERSION` 값을 올려야 기기에서 새 버전을 받습니다.
- 해석·재생 로직은 Android 앱(공식 `nwc-conv` 출력과 검증 완료)과 31개 파일에서 결과가 완전히 같음을 확인했습니다.

로컬 테스트: `node tools/serve.mjs` → http://localhost:8137
